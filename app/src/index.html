Atur server sinyal

NusaDesk butuh server sinyal untuk mempertemukan perangkat lewat ID. Jalankan server Anda sendiri (lihat docs/SELF_HOSTING.md) lalu masukkan alamatnya. Semua perangkat yang ingin saling terhubung harus memakai server yang sama.
